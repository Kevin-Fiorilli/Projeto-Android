# 🤖 Projeto Android

Este projeto consiste em uma página web sobre a história do mascote do Android, o famoso Bugdroid. O objetivo é apresentar curiosidades sobre a origem do mascote, seus criadores e a evolução do sistema operacional Android.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## 📚 O que aprendi neste projeto?

Durante o desenvolvimento, pratiquei conceitos importantes de HTML5 e CSS3, como:

- Estruturação semântica com HTML.
- Utilização de imagens e imagens adaptáveis (`picture` e `source`).
- Criação de links externos.
- Incorporação de vídeos do YouTube.
- Estilização de elementos com CSS.
- Organização de conteúdo utilizando tags semânticas.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em Desenvolvimento Web, colocando em prática os conhecimentos adquiridos e desenvolvendo minhas habilidades na criação de páginas web.
